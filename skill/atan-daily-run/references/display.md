# 怎么选组件

> 这里只回答「这段内容该用哪个组件、数据大概长什么样」。完整的字段语法在 `schema.md`；两边说法不一致时，**以 `schema.md` 为准**。

## 三步决策

1. **读者要回答什么**：一个数 / 一组对比 / 一个趋势 / 一个结构 / 一条流程 / 一个位置。
2. **数据是什么形状**：单值、一行多字段、多行同字段、层级、边列表、坐标。
3. **选组件**：查下表；命中「什么时候别用」就换一个。

## 速查表

| 读者要回答 | 组件 | 一行形状摘要 | 什么时候别用 |
|---|---|---|---|
| 这次是多少 | `metrics` | 1–4 个 `{label, value, unit}` | 超过 4 个指标 |
| 和上期/预算差多少 | `table` + `delta` 列 | `{name, value, delta}` | 只有两个数 |
| 谁高谁低 | `table`（按值降序） | `{name, value}` | 超过 30 行 |
| 排第一的是谁 | `table` 取前 5 或 `bar` | `{name, value}`，已排序 | 用 `pie` 表达排名 |
| 趋势 | `line` | `x`（期次）+ `y`（数值） | x 不是时间顺序 |
| 月度对比 | `bar`（可 `grouped` / `stack`） | `x` + 多个 `y` | 类别超过 20 个 |
| 占比 | `pie`（≤ 6 片）或 `bar` 堆叠 | `x`（名称）+ `y`（数值） | 切片 > 8、有负值 |
| 逐级筛选 | `funnel` | `x`（环节）+ `y`（数量） | 环节之间不是包含关系 |
| 结构 / 层级 | `treemap` / `sunburst` / `tree` | 扁平：`{name, value}`；层级：`x-shape: "tree"` | 层级超过 3 层 |
| 流程 / 流向 | `sankey` | `fields: [来源, 去向, 数值]` | 节点超过 15 个 |
| 双向关系强度 | `chord` | `fields: [来源, 去向, 数值]` | 关系数 < 4 |
| 少量节点的关系 | `graph` | 节点 + 块级 `links`；`layout: circular` | 节点 > 20、没有坐标还用 `none` |
| 多维度打分 | `radar` | `fields` ≥ 3 个数值维度 | 维度 > 8 |
| 两个量的关系 | `scatter` | `x` 与 `y` 都是数值 | x 是类别 |
| 发生在哪 | 地图块（`map: "china"` / `"world"`） | `fields: [经度, 纬度, 权重]` | 点位 < 3 |
| 时间分布密度 | `heatmap` | `x` + `y` + `value` | 格子总数 > 80 |
| 单个达成率 | `gauge` | `y`，`min` / `max` | 需要看趋势 |
| 一句话结论 | `quote` + `cite` | 纯文本 | 需要数据支撑 |
| 口径 / 提醒 | `note` | 纯文本（`tone` 区分） | 写成了段落 |
| 并列两栏 | `columns` | 2–3 栏，每栏一组块 | 栏内内容太长 |
| 一组相关块 | `card` | 标题 + 子块 | 只有一块 |

## 五条反模式

1. **用饼图讲排名**：切片一多就看不出顺序，改用排序表或条形。
2. **一张图塞十种颜色**：超过 6 类就合并成「其他」，或改用表格。
3. **柱状图堆 30 个类别**：标签会叠在一起，取前 10 或改表格。
4. **折线连缺失点**：`null` 断开就好，不要插值。
5. **为了排版编数据**：缺就写 `null` 并登记 `missing[]`。

## 误配 → 报错 → 改法

| 报错 | 原因 | 改法 |
|---|---|---|
| 散点的 x 必须是数值字段 | x 写成了期次或名称 | x 换成数值字段，或改用 `line` / `bar` |
| 系列缺少 y | 单值系列没写 `y` | 补 `y`；`fields` 系列改写成 `fields` |
| `graph` 只支持 circular / none | 写了 `force` | 删掉 `layout` 或改 `circular` |
| `graph` 用 none 布局时需要 fields | 固定坐标却没给坐标 | 补 `fields: [x, y]` |
| custom 需要 script | 自定义系列没写脚本 | 补 `charts/xxx.mjs`，只放 `.share/charts/` |
| 饼图切片 > 8 | 类别太多 | 取前 8 或改表格 |
| 主题河流的 x 不是日期 | 横轴不是时间 | 换 `date` 字段，或改用堆叠面积 |
