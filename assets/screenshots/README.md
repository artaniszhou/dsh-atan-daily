# 截图

README 的「界面预览」引用这里的四张图片，按下表准备并保持文件名一致即可：

| 文件 | 内容 |
| --- | --- |
| `task-list.png` | 任务列表：统计条、搜索框、任务行与调度状态 |
| `task-editor.png` | 新建 / 编辑弹窗：口语与 cron 时间输入、时区选择 |
| `run-history.png` | 运行历史抽屉：状态、耗时、报告与会话 |
| `settings.png` | 工作目录：路径修改与创建（可选，不需要可删掉 README 中对应段落） |

建议宽度 1000px 以上（当前素材约 1000px），PNG 或 WebP，浅色或深色保持统一；截图前可收起无关窗口。
